    About permanent vs temporary forwards

    Forwards added here are temporary (runtime): they are dropped when the Mutiauk process restarts. Forwards declared in the config file are permanent and survive restarts.

    To make a temporary forward permanent, add it to the expose.forwards list in your config file, then reload:

    expose:
  enabled: true
  forwards:
    - key: my-key
      type: folder        # or: tcp
      path: /srv/share    # folder: absolute path
      # target: 127.0.0.1:22   # tcp: host:port
      comment: "optional"
    Then: sudo mutiauk daemon reload --config <path> (or restart).
